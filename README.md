# SightPilot AI

Build a modern desktop AI copilot dashboard called SightPilot AI.

Design a sleek, futuristic but professional interface with a dark navy background, subtle blue and violet accents, rounded cards, clean typography and a minimal layout.

Include:

1. A sidebar with Overview, Activity History, Settings and Help.

2. A main dashboard showing a screen-sharing/screenshot preview area.

3. A prominent microphone button with a voice listening animation.

4. A command transcription panel.

5. An AI task planning panel with numbered proposed actions.

6. Approve Task and Cancel Task buttons.

7. An execution progress indicator.

8. A verification/result panel.

9. A task log showing previous actions.

Make the interface responsive and polished. Use realistic demo data initially. Build the frontend only; the desktop computer-control functionality will be connected separately through Python.
